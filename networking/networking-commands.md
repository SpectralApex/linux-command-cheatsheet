# Linux Networking Commands

## ping
Check connectivity.

```bash
ping google.com
```

## ifconfig
Display network interfaces.

```bash
ifconfig
```

## ip
Modern networking utility.

```bash
ip a
ip route
```

## netstat
Display network connections.

```bash
netstat -tulnp
```

## ss
Socket statistics.

```bash
ss -tulnp
```

## curl
Send HTTP requests.

```bash
curl https://example.com
```
